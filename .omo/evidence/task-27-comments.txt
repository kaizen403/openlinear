## What it does

- Fetches comments via apiFetch from T10 backend `GET /api/tasks/:taskId/comments`
- Renders thread with author avatar, relative time, body
- Composer at bottom with `@` autocomplete: triggers Popover listing team members; selecting inserts `@username`
- Submits via POST /api/tasks/:taskId/comments — T10 backend parses mentions, creates Notification rows
- Subscribes to SSE `comment:created` (from T8/T10 per-user filtered) → live updates other browser tabs
- Edit/delete own comments inline (PATCH/DELETE via T10 routes); permission checks server-side via assertCommentOwned
