ENDPOINTS ADDED (apps/api/src/routes/usage.ts)
----------------------------------------------
  GET /api/usage/summary
    - requireAuth
    - Scope: AgentRuns where userId === req.userId OR task.teamId IN getUserTeamIds(req.userId)
    - Window: last 30 days (UTC midnight aligned)
    - Returns: { totalCostUsd, totalRuns, totalInputTokens, totalOutputTokens,
                 avgCostPerRun, daily: [{date, costUsd, runs}] }
    - daily series is zero-filled across all 30 days so the chart is dense

  GET /api/usage/by-task?page=&pageSize=&sort=cost|runs|recent
    - requireAuth + validateQuery(zod)
    - Same scope as /summary
    - Prisma groupBy by taskId with _sum(cost,tokens), _count, _max(startedAt)
    - sort: cost  -> orderBy { _sum: { costUsd: 'desc' } }
            runs  -> orderBy { _count: { taskId: 'desc' } }
            recent-> orderBy { _max:   { startedAt: 'desc' } }
    - Joins Task title/identifier separately (no relation include in groupBy)
    - Returns: { items: [{taskId, taskTitle, taskIdentifier, runs, totalCostUsd,
                          totalInputTokens, totalOutputTokens, lastRunAt}],
                 page, pageSize, total, sort }

SECURITY / TENANCY
------------------
  - Scope filter is { OR: [{ userId }, { task: { teamId: { in: teamIds } } }] }
  - When teamIds is empty, only userId clause is used (own runs still visible).
  - No raw SQL; no `as any`; no `@ts-ignore`.
  - Decimal -> number conversion via Prisma Decimal.toNumber() (with toString
    fallback) and rounded to 6 decimal places to match @db.Decimal(12,6).
