Performance reasoning per change:
----------------------------------
- transform/opacity → composite-only (GPU). No layout, no paint.
- width/height/box-shadow/border-color → trigger layout and/or paint per frame.
- backdrop-filter → expensive offscreen pass; defer during drag.
- prefers-reduced-motion (CSS, T21) handles browser default. The framer-motion
  hook complements that by NOT scheduling animation frames at all when the user
  prefers reduced motion — saves CPU even when CSS would no-op the visual.
- Infinite brain pulse running while overlay is open was wasting a render frame
  every ~8ms on a 240Hz display for an animation the user can't see (covered
  by the pill). Gated to idle state only.
