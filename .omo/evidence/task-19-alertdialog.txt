## Pattern used (consistent across all 4)

- `useState<T | null>(null)` (or `useState<boolean>(false)` in sidebar) holds the pending action target
- Click handler does `setX(target)` instead of synchronous `confirm()`
- A separate `confirmX()` async function performs the deletion when the user confirms
- `<AlertDialog open={x !== null} onOpenChange={(open) => { if (!open) setX(null) }}>` controls visibility
- `<AlertDialogAction>` uses `cn(buttonVariants({ variant: "destructive" }))` for the red button (T2 primitive defaults to non-destructive)
- `onClick={(e) => { e.preventDefault(); void confirmX() }}` prevents Radix's auto-close so the in-flight `disabled` + "Deleting..." label render before the dialog dismisses on success
- `<AlertDialogCancel>` outline variant from T2's defaults
- Loading state via `isXing` boolean disables both buttons during the request
